# 个人博客重构视觉验收

验收日期：2026-07-26

## 概念稿与实现对照

| 对照项 | 概念稿目标 | 实际实现 |
| --- | --- | --- |
| 顶部导航 | 轻量悬浮导航、圆角玻璃层 | 桌面端使用悬浮胶囊导航，移动端折叠菜单保持相同材质 |
| 首页结构 | 大幅主卡、文章流、标签与日历侧栏 | 主卡读取真实文章，侧栏与文章列表共享真实标签和日历数据 |
| 卡片背景 | 封面图与柔和色块都能成立 | 支持文章封面、自定义图片、预设渐变、纯色、站点默认和无背景，并支持焦点位置 |
| 曲线与玻璃 | 水面感曲线、半透明层次 | 页面背景曲线、玻璃模糊、内高光与柔和阴影统一由设计变量控制 |
| 文章阅读 | 大封面、正文白板、侧边工具 | 已实现阅读进度、目录、代码复制、图片灯箱、点赞、分享二维码、返回顶部与评论 |
| 写作工作台 | 沉浸式分栏编辑与预览 | 编辑器独立于公开导航，支持实时 Markdown 预览、粘贴/拖拽图片即时预览和发布设置 |
| 后台工作台 | 独立侧栏、内容优先 | 后台独立壳层覆盖内容、互动、标签、资源、用户、站点与安全模块 |
| 移动端 | 单列、保留大圆角与留白 | 390×844 视口验收通过，导航、文章卡、菜单和操作区自动重排 |
| 明暗模式 | 同一材质在明暗色中自然过渡 | 亮色、暗色、跟随系统三种模式，使用视图过渡并兼容减少动态效果设置 |
| 动效 | 克制的流体反馈 | 页面入场、卡片悬浮、曲线漂移、鼠标拖尾和主题过渡均统一节奏 |

## 文案核对

- 前端未写入示例文章标题、虚构介绍、情绪化口号或假数据。
- 首页仅展示站点设置、文章、标签、日历等真实数据；站点名和简介由后台配置。
- 空状态只描述当前系统状态和可执行动作，不替用户表达生活态度。

## 验收视图

- 桌面：首页亮色、首页暗色、文章、日历、编辑器、后台总览。
- 移动：390×844 首页与展开菜单。
- 交互：主题切换、搜索、图片型文章发布条件、正文型文章发布条件、任意标签回车创建、分享二维码。
