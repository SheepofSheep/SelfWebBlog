# 流体鼠标交互动效设计

## 目标

用一套克制的“连续光带拖尾 + 点击扩散波纹”替换现有圆点拖尾。效果服务于个人博客的液态玻璃风格，但不接管系统鼠标、不阻塞点击、滚动或文本选择，也不在触屏、粗指针和系统减少动效环境中运行。

## 方案选择

采用单 Canvas 覆盖层。SVG Path 便于编辑但高频更新路径和滤镜的稳定性较差；WebGL 性能充足但复杂度与依赖都超出本需求。Canvas 能在一个无交互层中同时完成丝带和波纹，并严格控制点数、DPR 和渲染时长。

## 组件与数据边界

- 保留全局 `PointerTrail` 挂载位置，将内部圆点 DOM 重构为一个 `canvas`。
- 新增纯函数模型模块，负责启用条件、速度映射、点击手势判定、轨迹点裁剪和波纹生命周期；组件负责浏览器事件、Canvas 尺寸、逐帧推进和绘制。
- Canvas 固定覆盖视口，设置 `pointer-events: none`、`aria-hidden="true"`，层级低于弹窗和通知，不隐藏系统鼠标。
- 鼠标事件只更新目标坐标、速度、悬停状态和按压手势；全部插值、几何计算与绘制均在 `requestAnimationFrame` 中进行。

## 连续光带

- 维护最多 32 个中心线点，并为头部使用带阻尼的弹簧插值；快速移动时提高保留长度，慢速移动时主动收短。
- 由相邻点切线计算法向量，生成左右边缘；使用二次贝塞尔曲线闭合为一条连续丝带，不创建圆点、节点或粒子。
- 宽度从尾部逐渐增大，在靠近指针处保持清晰并轻微收尖；透明度沿轨迹渐增，尾端快速衰减。
- 绘制一层低透明柔光和一层较清晰主体，模糊范围受限，避免霓虹灯效果。
- 指针停下后约 260ms 内收缩、淡出并停止动画帧；新移动会立即唤醒。
- 悬停 `a`、可用 `button`、按钮/链接角色和文章卡片时，丝带缩短约 15%、亮度小幅提高并贴近指针。输入框、编辑器、代码块和可选文本区域不应用该反馈；元素原有 hover 样式继续负责自身的轻微位移和高光。

## 点击波纹

- 记录主键 `pointerdown`，在 `pointerup` 时以移动距离阈值判定为点击；右键、中键、取消事件和超过阈值的拖拽不生成波纹。
- 每次点击生成一个波纹对象，绘制一层主环和一层轻微延迟的弱环；圆周加入极小的正弦形变，保持连续闭合而不产生碎屑。
- 波纹在 520ms 内扩散、变细、淡出。最多同时保留 4 个波纹对象，超出时淘汰最旧对象。
- 监听器不调用 `preventDefault` 或 `stopPropagation`，原点击事件保持不变。

## 主题与无障碍

- 从根元素的 `--accent` 读取颜色，并在主题属性变化时刷新；无法解析时使用暖黄色 `#d7a642`。
- `prefers-reduced-motion: reduce`、站点减少动效、粗指针、无 hover、触摸输入、页面隐藏或窗口失焦时立即清空并停止。
- 页面恢复后不主动启动；只有新的鼠标移动或有效点击才唤醒渲染。
- 画布只提供装饰，不暴露可访问节点，不修改鼠标指针样式。

## 性能与生命周期

- DPR 上限为 1.75，并按视口总像素量继续下调，避免高分屏画布过大。
- 轨迹点上限 32、并存波纹上限 4；不引入动画库。
- resize 只标记尺寸更新，由下一帧统一处理。
- 组件卸载时取消动画帧、断开 MutationObserver、移除媒体查询和窗口事件监听，并清空悬停与按压状态。

## 测试与验收

1. 单元测试覆盖动效启用条件、速度自适应长度、主键轻点判定、拖拽/右键拒绝、波纹数量和 520ms 生命周期。
2. E2E 验证页面只渲染单 Canvas 且 `pointer-events: none`，不再存在圆点 DOM。
3. E2E 通过真实鼠标移动检查 Canvas 获得非透明像素，并验证停止后自动清空。
4. E2E 验证左键点击生成波纹，右键和拖拽不增加波纹，同时原按钮点击仍然生效。
5. E2E 在 `prefers-reduced-motion: reduce` 下确认画布不绘制；移动视口确认粗指针场景关闭。
6. 运行单元测试、lint、格式检查、构建与完整 Playwright 回归，并在真实浏览器中检查桌面截图、控制台和交互。
