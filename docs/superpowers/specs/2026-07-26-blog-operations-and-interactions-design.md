# SelfWebBlog 内容运营与互动体验设计

日期：2026-07-26

状态：已确认进入 Goal 实施

视觉方向：B — 紧凑工作台 + 首页日历浮层放大

## 1. 目标与边界

本轮在不删除现有文章、标签、评论、用户、媒体和站点资料的前提下，完成公开端与管理端的第二轮整合：修复归档布局；将日历从独立页面收回首页；统一头像、弹窗和主题动效；补齐评论表情、任意层语义回复、称号同步和可排序置顶；让用户资料、媒体、站点链接、评论、文章生命周期与概览数据真正可管理。

管理端保持 `/admin?tab=` 深链接与现有八个入口，但拆分为独立面板。公开端继续保持圆润、克制的液态玻璃个人博客风格，不增加解释性口号或示例文案。

## 2. 视觉与交互原则

- 使用现有蓝灰色、圆角玻璃和细描边语言，不切换为通用企业后台模板。
- 公开端保持留白；管理端提高信息密度，通过工具栏、分组、筛选、分页和可折叠详情管理大量数据。
- 所有站内确认、编辑和详情浮层统一使用同一套 Dialog：圆角玻璃容器、遮罩、明确标题、主次按钮、提交中状态、字段错误、Escape 关闭、焦点锁定与关闭后焦点归还。
- 原生 `alert`、`confirm`、`prompt` 全部移除。
- 动画以状态变化为目的：日历放大、月份切换、Dialog 进出、主题切换和列表重排有短促过渡；减少动效时立即切换，不播放扩散或位移动画。

## 3. 公开归档

当前重叠来自年份标题与所有文章链接共同参与两列 Grid 自动排布。新结构为每年一个显式的 `年份列 + 文章列表列`：文章链接只在列表列内纵向排列，不再与年份争夺网格单元。

- 年份按降序排列，同年文章按创建时间降序。
- 筛选覆盖标题、摘要、正文和标签。
- 每条记录使用稳定的日期列、标题和标签；长标题允许换行但不挤压日期。
- 移动端切为单列：年份在上，文章列表在下，禁止横向溢出。
- 加载所有公开文章分页，而不是固定只取前 100 篇。
- “归档页”仍是已发布文章的时间索引，不展示后台已收纳的 `ARCHIVED` 内容。

## 4. 首页日历

删除 `/calendar` 路由与独立 `CalendarPage`。首页侧栏日历升级为共享 `CalendarWidget`：

- 小窗内可切换上月、下月和回到本月，快速切月采用请求序列号，旧响应不能覆盖新月份。
- 有文章的日期显示清晰圆点与文章数量；空日期不触发详情。
- 点击有文章日期，在小窗附近展开日期文章浮层，列出当天全部文章，标题可直接跳转。
- 点击“放大”使用统一 Dialog 展示完整月份；从小窗到大窗使用缩放、透明度和轻微位移动画。
- 大窗继续支持切月、选择日期与跳转文章；移动端使用接近全屏的底部浮层并允许内部滚动。
- 支持关闭按钮、遮罩、Escape、焦点管理与减少动效。
- 日历失败显示轻量重试，不影响首页文章列表。

## 5. 头像与用户资料同步

新增共享 `AppAvatar` 组件，统一尺寸、圆角、加载失败和昵称首字回退。

- 公共导航的账户入口读取当前登录用户 `avatarUrl`；未登录显示账户图标。
- 管理后台侧栏顶部和底部账户信息读取当前管理员头像与昵称，不再显示固定蓝色占位图标。
- 公开站点品牌头像仍读取站点资料 `site.avatarUrl`，与登录账户头像保持语义分离。
- 个人资料页支持修改显示昵称和上传头像；保存成功后立即更新 session store，刷新后保持。
- 活跃用户的历史评论在查询时优先显示当前用户昵称、头像和称号；用户被删除后回退评论快照，历史内容不丢失。
- 登录用户名不提供修改；“改名”明确指公开显示昵称。

## 6. 评论、表情与回复

### 6.1 表情包

复用 `public/images/emojis` 中现有 33 张图片，建立固定目录与 `EmojiPicker`。评论内容保存安全 token（例如 `[sticker:名称]`），展示时只解析白名单资源；普通文本始终转义，不允许任意 HTML 或任意图片地址。

- 根评论和所有回复使用同一选择器。
- 插入 token 时保留输入焦点和光标位置。
- 兼容历史内容中的 `/images/emojis/` Markdown 写法，但只渲染白名单路径。
- 表情图片有替代文本、固定最大尺寸，移动端不会撑破评论卡片。

### 6.2 任意层语义回复

数据继续使用 `rootId + replyToId`，视觉上保持单层回复列表，避免无限缩进。任何回复都可以继续回复，展示“甲 回复 乙”；发送成功后自动展开对应线程并定位新回复。

- 根评论和回复都支持点赞、回复及管理员三点菜单。
- 回复默认折叠，按钮显示准确数量。
- 后端返回 `replyToNickname`，前端不依赖猜测。
- 删除父回复后，后代仍保留并显示“回复已删除用户”或快照名称，不破坏线程。

### 6.3 称号同步

称号名称限制 20 个字符，样式使用白名单枚举：`default`、`blue`、`green`、`gold`、`rose`。管理 Dialog 提供实时预览、清空称号和保存状态。

公开根评论、回复和后台列表均优先读取当前用户称号；用户删除后使用互动快照。

### 6.4 可排序置顶

根互动新增 `pin_order` 和 `pinned_at`。置顶时默认排在现有置顶末尾；后台可用上移、下移调整顺序。公开和后台统一按：

1. 已置顶优先；
2. `pin_order` 升序；
3. 创建时间降序。

只有已发布的根互动可置顶；回复不能置顶。取消置顶会清空顺序，并压缩同目标剩余顺序。多个置顶始终稳定显示在最上方。

## 7. 管理工作台

保留统一侧栏与 URL tab 状态，将 `AdminPage.vue` 拆为 `OverviewPanel`、`ContentPanel`、`InteractionsPanel`、`TagsPanel`、`MediaPanel`、`UsersPanel`、`SitePanel`、`SecurityPanel`。每个面板独立管理加载、空状态、错误、分页和变更反馈，共享 Dialog、Toast、分页器和批量操作栏。

### 7.1 概览

保留已发布、草稿、待处理、用户、媒体数字卡片，补充孤立媒体和数据库状态。新增最近 14/30 天趋势：独立浏览、互动、发布文章三条序列，默认 14 天，可切换 30 天。

- 使用轻量 SVG 折线/面积图，不引入大型图表库。
- 深浅主题均有足够对比度，悬停显示日期与数值。
- 图表下提供可访问文字汇总，零数据日期补零，不出现 NaN。
- 时区按 `Asia/Shanghai` 聚合；旧明细不存在的日期按零处理，不伪造历史数据。

### 7.2 文章管理与收纳归档

当前项目没有文章生命周期“归档”能力，本轮新增 `ARCHIVED`：

- 状态流为 `DRAFT → PUBLISHED → ARCHIVED → PUBLISHED`；归档不删除正文、标签、媒体、评论、点赞或浏览数据。
- 后台分为已发布、草稿、已归档，可搜索、分页、多选、批量归档、批量恢复和批量删除。
- 操作收进每行三点菜单，编辑保持主操作。
- 所有公开查询明确使用 `status = PUBLISHED`。归档文章不出现在首页、文章发现、公开归档、搜索、标签、日历、统计中，匿名详情返回 404；管理员仍可读取和编辑。
- 记录 `archived_time`，恢复发布后保留原创建时间。

### 7.3 评论管理

- 顶部提供状态、内容类型、是否置顶、关键字筛选与分页。
- 列表先展示根互动，回复折叠在其下；显示文章来源、作者头像、昵称、称号、地区、时间、点赞和回复数。
- 支持管理员回复、审核/隐藏、置顶/取消、置顶排序、删除，以及选中后的批量审核、隐藏或删除。
- 操作成功后进行局部更新，失败回滚并显示统一错误，不整页闪烁。

### 7.4 媒体管理

前端改接管理员媒体 API。网格和紧凑列表可切换，展示缩略图、尺寸、体积、用途、上传者、创建时间、引用状态与引用数量。

- 支持关键字、用途和 `ACTIVE/ORPHANED` 筛选、分页与多选。
- “扫描引用”同时检查正文、封面、旧 `imageUrl`、文章背景、站点头像与背景。
- 只有确认无引用的资源允许删除；删除前统一确认，支持批量删除孤立资源。
- 可预览原图、复制地址和查看引用文章。
- 删除在事务边界内处理记录与文件失败，失败时保留可重试状态，不假报成功。

### 7.5 用户管理

- 展示头像、显示昵称、登录名、邮箱、角色、称号、注册时间和风险提示。
- 支持关键字、角色和称号筛选与分页。
- 称号使用统一表单 Dialog 编辑，不再连续调用原生 prompt。
- 删除用户显示影响说明；历史评论保留快照，媒体和点赞关系采用明确清理策略。
- 当前管理员可以从个人资料页修改自己的显示昵称和头像，后台侧栏即时同步。

### 7.6 站点与任意链接

保留昵称、简介、头像、背景、建站日期和关于时间线。新增有序的自定义链接集合，每项包含：标签、URL、可选图标键、启用状态和排序值。

- 支持新增、编辑、启用/停用、拖动排序和删除任意数量链接。
- URL 仅允许 `https://`；邮箱使用 `mailto:` 并校验格式。
- 现有 GitHub、Bilibili、邮箱、网站 JSON 数据在迁移时转换为链接记录，原数据不删除。
- 公开关于页与个人链接区按排序显示启用项，外部链接使用安全 `rel`。

## 8. 主题切换

外观控制器统一主题模式、系统偏好、用户减少动效设置和进行中的动画。

- 支持 light、dark、system；首屏脚本继续避免闪烁。
- 支持 View Transition 时从按钮点击点进行圆形扩散；快速连续切换采用序列号，只有最后一次选择生效。
- 用户设置减少动效或系统偏好减少动效时立即切换。
- 不支持 View Transition 时给根节点短暂添加 `theme-changing`，让背景、玻璃边框、文字、阴影和表单控件使用一致的 CSS 过渡。
- 切换过程中不锁死界面，不产生白屏或双重 crossfade。

## 9. 后端模型与迁移

使用新增 Flyway 迁移，保持非破坏性：

- `post`：新增 `archived_time`，status 允许应用层使用 `ARCHIVED`，增加状态与归档时间索引。
- `interaction`：新增 `pin_order`、`pinned_at` 与排序索引。
- 新建 `site_link`：`id`、`label`、`url`、`icon_key`、`enabled`、`sort_order`、时间字段；从现有 `social_links` 迁移已知项目。
- 媒体表增加引用数量或通过扫描结果响应返回引用详情；旧媒体记录与上传目录均保留。
- 趋势数据尽量从现有 `post_view_daily`、`interaction` 和 `post` 聚合，不制造无法还原的历史事件。

迁移继续使用现有 SQLite 备份回调。迁移测试必须从已有数据版本升级并核对文章、标签关系、互动、用户、媒体和站点资料数量不变。

## 10. API 与数据流

- 公开文章、搜索、标签、日历和详情统一只读取 `PUBLISHED`。
- 管理文章列表接受 status、keyword、page、size；归档/恢复使用专用状态变更接口并返回最新文章。
- 日历响应继续按日期返回文章摘要，前端以请求版本避免乱序覆盖。
- 互动响应将当前用户资料覆盖快照并返回 `replyToNickname`、`pinOrder`；分页只分页根互动，回复按线程返回。
- 管理媒体 API 提供分页、筛选、扫描、引用详情和孤立删除。
- 站点链接使用独立管理员 CRUD/排序接口；公开 about 响应包含启用链接。
- Dashboard overview 增加 `range` 参数与补零后的趋势数组。

所有 Long ID 继续按字符串传输，避免 JavaScript 精度丢失。

## 11. 错误处理与安全

- 所有 mutation 显示 pending，禁止重复提交，失败保留用户输入并给出可恢复错误。
- Dialog 中的危险操作明确对象名称和影响范围。
- 评论表情只解析白名单 token；站点链接限制安全协议；上传继续校验真实图片类型和尺寸。
- 媒体引用扫描采取“宁可保留，不误删”策略；不确定引用视为 ACTIVE。
- 权限在后端强制校验，前端隐藏按钮不能作为安全边界。
- 归档、置顶排序、称号和批量操作采用事务，避免半完成状态。

## 12. 测试与验收

测试采用红—绿—重构：每个行为先写失败用例，再实现最小修复。

### 前端单元测试

- 归档显式年份排序与同年文章排序。
- 日历月份边界、闰年、多文章日期、请求 latest-wins 和弹窗选择模型。
- 评论 token 白名单渲染、回复目标归一化、置顶稳定排序。
- 用户资料同步、头像回退和主题 latest-wins/reduced-motion。
- 自定义链接校验、媒体筛选和 Dashboard 补零图表模型。

### 后端测试

- `ARCHIVED` 生命周期及所有公开查询不可见。
- 资料更新的 null、长度、鉴权、头像替换与历史互动资料同步。
- 任意层回复读取、replyToNickname、称号同步、置顶顺序和重排。
- 媒体扫描覆盖所有引用字段、孤立删除和失败安全。
- 自定义链接 CRUD、排序、协议校验与旧 JSON 迁移。
- Dashboard 14/30 天聚合、零数据、时区边界。
- 从已填充 V10 数据库迁移后，原数据计数与关联保持。

### 浏览器验收

- 桌面、平板、手机验证归档不重叠且无横向滚动。
- 首页小日历切月、发文标记、日期文章浮层、放大/关闭与文章跳转。
- 导航和后台头像在修改后即时同步并在刷新后保持。
- 根评论、回复回复、表情、点赞、折叠、称号和多个置顶顺序。
- 统一 Dialog 替代全部原生弹窗。
- 后台文章、评论、媒体、用户、站点和概览完整流程。
- 明暗主题连续快速切换与减少动效模式无闪屏。
- 页面无 console error、HTTP 5xx、不可达操作和布局溢出。

最终门槛为前端单测、Lint、格式检查、生产构建、Playwright E2E 与后端完整 Maven 测试全部通过。

## 13. 明确不做

- 不引入第三方富文本评论或任意 HTML 评论。
- 不实现无限 DOM 嵌套；多级关系通过单层线程中的回复目标表达。
- 不伪造迁移前不存在的浏览趋势。
- 不把“文章管理已有归档”之类的说明写入界面；交付时直接告知实际实现结果。
- 不删除真实数据库、上传目录或现有内容。
