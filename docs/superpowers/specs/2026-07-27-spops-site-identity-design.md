# Spops 站点标识与备案页脚设计

## 目标

将浏览器标签页的旧“博客”名称和紫色闪电图标完整替换为 `Spops` 品牌标识，并在所有公共页面底部加入可访问、可点击的备案信息。整体延续现有蓝色液态玻璃风格，不增加口号、版权宣言或其他说明文字。

## 视觉方案

- 标签页标题固定为 `Spops`。
- favicon 使用蓝色圆角玻璃底和白色流线 `S`，在 16×16 像素下仍保持清晰；不保留旧闪电或 Vue 默认图形。
- 页脚只包含一个轻量玻璃胶囊：左侧为小型“晋”字印记，右侧为 `晋ICP备2026007967-1号`。
- 页脚颜色读取现有 `--accent`、`--glass`、`--line` 和 `--muted` 主题变量，自动适配亮色、暗色及自定义背景。
- 悬停仅有轻微上移、边框提亮和柔和高光，不增加夸张动画。

## 组件与页面行为

- 新建独立 `SiteFooter.vue`，由 `App.vue` 在非沉浸式页面渲染。
- 管理后台和写作页继续保持沉浸式布局，不显示备案页脚。
- `.app-shell` 使用纵向弹性布局，正文占据剩余空间，保证短页面的备案信息位于视口底部。
- 备案号链接到 `https://beian.miit.gov.cn/`，在新窗口打开，并使用安全的 `rel` 属性。

## 可访问性与兼容性

- 备案链接保留清晰的键盘焦点状态和足够的文字对比度。
- 装饰性“晋”字印记不重复朗读。
- 移动端缩小间距但不缩小可点击区域。
- 不依赖 JavaScript 动画或第三方图标库，favicon 和页脚在构建失败降级场景下仍可用。

## 非目标

- 不新增后端站点设置字段。
- 不修改用户昵称、头像、文章内容或导航文案。
- 不增加版权年份、宣传语或 AI 风格描述。
- 不保留旧 favicon 的任何图形元素。

## 验证

- 静态检查标签页标题、favicon 引用和备案链接。
- 运行前端格式检查、测试、Lint 与生产构建。
- 部署后检查首页和主要深链均引用新 favicon，页脚备案号与链接正确，并确认后台/写作页不渲染页脚。
